# 项目 1：从零实现 Tiny GPT

状态：待实现。目标是理解训练机制，不是得到通用聊天模型。

## 分步任务

- [ ] PyTorch 基础验收。
- [ ] 自制或选取许可明确的文本；记录来源、许可、数据哈希。
- [ ] 先按文档划分训练/验证/测试，再制作窗口，避免重叠泄漏。
- [ ] 实现字符词表与编码/解码，定义未知字符处理。
- [ ] 实现因果多头注意力、位置嵌入、前馈网络、残差、LayerNorm。
- [ ] 实现 next-token loss、训练/验证、随机种子、checkpoint 与恢复。
- [ ] 实现 temperature 和 top-k 采样。
- [ ] 在固定预算下比较至少两项超参数，并报告失败实验。

## 有意义的验证

未来 token 改变时，早期位置 logits 应保持不变；单批次可过拟合；checkpoint 重载后 eval 输出一致。记录 train/validation loss、token 级交叉熵、参数量、训练 token 数、耗时和设备。

## 验收与面试问题

提交实际训练命令、配置、loss 曲线、生成示例和至少一份消融报告。说明张量形状、mask、teacher forcing、训练与推理差异。字符级指标不能直接与其他 tokenizer 的模型对比。
