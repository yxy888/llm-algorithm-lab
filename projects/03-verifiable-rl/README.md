# 项目 3：整数算术任务的可验证奖励 RL

状态：待实现；依赖前两个阶段与强化学习基础。

## 最小任务

用独立随机种子生成整数加减乘任务，最终答案格式固定为 `<answer>整数</answer>`。用确定性数值比较验证答案，不使用字符串 eval 或执行模型代码。

- [ ] 定义任务难度、数值范围、训练/验证/测试划分与去重规则。
- [ ] 对奖励函数写边界测试：多答案、错误标签、空白、负数、超长输出。
- [ ] 先评测基础模型和 SFT 模型，检查任务是否过难或已饱和。
- [ ] 在小规模实验上实现/使用 GRPO，记录对应库版本和完整配置。
- [ ] 比较正确性奖励与“正确性 + 格式”奖励。
- [ ] 用独立评测器检验结果，避免训练奖励的解析漏洞变成虚假提升。
- [ ] 对比基础/SFT/RL；保持评测解码预算一致，报告训练计算开销。
- [ ] 使用多个种子或明确报告单次实验的局限。

## 指标与验收

主要指标：全部测试题的数值正确率。辅助指标：格式合规率、平均生成长度、训练奖励和耗时。提供分难度与未见模板/范围上的结果，分析奖励增加但正确率不升的情形。

此项目的算术结果不能直接证明真实代码 Agent 或通用数学推理能力。扩展代码任务时另行设计隔离执行与评测环境。
