## 指标与验收

报告 JSON 有效率、字段准确率/集合 F1，以及无效输出数量。禁止只报告成功解析样本上的成绩；同时评估全部样本。测试集不用于挑选超参数。

完成报告应包括提示词、解码参数、数据样例、错误分类和基线比较。解释 LoRA 为什么降低训练开销，以及 rank、学习率、训练轮数的取舍。
