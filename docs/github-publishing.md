# 发布到 GitHub

当前本地内容为学习与实验起步框架，不能描述为已完成训练的算法成果。

推荐仓库名：`llm-algorithm-lab`。如需面试官免登录查看，可创建公开仓库；发布前检查文件是否适合公开。

## 连接后发布

连接 GitHub 插件并确认账号后，创建仓库，再把此目录提交并推送。当前没有预设用户名或远程地址，不应猜测账号。

## 手动备用路径

1. 在 https://github.com/new 创建同名空仓库，不勾选自动生成 README。
2. 若已配置 Git 认证，在此目录运行 `git remote add origin <仓库实际地址>`。
3. 执行 `git push -u origin main`。

首次推送失败时保留本地提交，先检查认证和远程地址，不要强制覆盖远程。后续每完成一个可验证阶段再提交，保留真实学习轨迹。
