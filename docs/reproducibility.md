# 复现与评测规范

每次实验必须记录：

1. Git commit、Python/依赖版本、操作系统、设备与显存。
2. 数据来源、许可、哈希、划分规则、去重规则与样本数量。
3. 模型/tokenizer revision、训练与生成配置、随机种子。
4. 基线、对照组、实际预算和评测脚本版本。
5. 原始日志、逐样本预测、全部样本指标和失败案例。

大文件放外部存储时提供可访问地址与校验和；不要把密钥放进配置。没有跑过的实验标注“待运行”；示例、合成数据与真实成绩明确区分。缺少算力时报告小规模结果和局限，不编造提升。

## 提交前验收

- 新环境可按 README 运行。
- 同一测试集、统一解码预算比较模型。
- 无测试集调参、无重复样本泄漏。
- 对借鉴代码、AI 辅助和个人贡献作明确说明。
- 项目首页状态与实际提交内容一致。
